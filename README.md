# Fundamental Booster – Personal Data Collector

## Project Description

Fundamental Booster is a Python-based interactive personal data collector. It takes basic information from the user and displays the collected data along with its data type and memory address.

## Features

* Takes user's name as input.
* Takes age, height, and favourite number.
* Displays the collected information.
* Shows the data type of each value.
* Displays the memory address using `id()`.
* Calculates the user's birth year from their age.

## Technologies Used

* Python 3

## Concepts Used

* Variables
* User Input
* Type Casting
* Data Types
* `type()`
* `id()`
* Basic Arithmetic Operations

## How to Run

1. Open the Python file in Jupyter Notebook, VS Code, or any Python IDE.
2. Run the program.
3. Enter your name, age, height, and favourite number.
4. The program will display the collected information and calculated birth year.
